# Brida-машина — как начать работать на своём Mac

Доска, скилл и коннекторы (Higgsfield, ClickUp) общие через аккаунт Claude — они уже работают.
Эта папка добавляет то, что живёт на самом Mac: генерацию через Kie.ai, озвучку ElevenLabs и черновую нарезку.

## Один раз на новом Mac

1. **Google Drive для компьютера.** Скачать с google.com/drive/download, установить и войти **общим** Google-аккаунтом.
   На первом экране **снять все галочки** (Documents, Desktop, Downloads), дальше режим **Stream files**.
   Эта папка `brida-machine` появится сама — её ничего искать не нужно.
2. **Установка.** Открыть приложение Claude → вкладка **Code** → написать: **«запусти установку брида машины»**.
   Claude сам запустит установщик. Он скачает нужные программы и попросит вставить два ключа — Kie и ElevenLabs.
   Ключ вставляется **в окошко установщика, не в чат**. В конце будет «Kie: … кредитов, ElevenLabs: … символов».
3. Готово. Дальше всегда: в Claude написать **«запусти брида машину»**.

## Что где лежит

- **Эта папка (Google Drive, общая):** скрипты. Правки появляются у всех сами. Ключей и программ здесь нет.
- **Личная папка `~/.brida` на каждом Mac:** ключи, ffmpeg, конвертер звука, скачанные файлы. Никуда не синхронизируется.

## Важно

- Не удалять программу Google Drive и не выходить из аккаунта в ней — иначе машина потеряет эту папку.
- Кредиты Kie, ElevenLabs и Higgsfield общие: машина всегда называет цену и ждёт «да».
- Ключи никогда не писать в чат.
